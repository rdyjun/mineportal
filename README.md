# 마인포탈 (MinePortal)

브라우저에서 로그인 한 번으로 실제 마인크래프트 서버에 접속해서 채팅을 보고 보낼 수 있는
웹 서비스예요. 클라이언트 설치 없이 브라우저에서 바로 체험할 수 있고, IP가 안정적으로
고정되어야 하는 서버(화이트리스트 서버 등)를 위한 데스크톱 클라이언트도 제공해요. 실제
서비스는 [mineportal.kr](https://mineportal.kr)에서 운영 중이에요.

## 이게 어떤 서비스인가요

마인크래프트는 원래 전용 런처/클라이언트를 설치해야만 서버에 접속하고 채팅을 볼 수 있어요.
마인포탈은 그 과정을 걷어내고, **Microsoft 계정으로 로그인만 하면 브라우저에서 여러 서버의
채팅을 동시에 보고, 보내고, 명령어까지 칠 수 있게** 해주는 서비스예요.

- 서버 주소를 등록해두면 여러 서버에 동시 접속해서 각 서버의 채팅을 그리드로 한눈에 볼 수
  있어요.
- 채팅뿐 아니라 서버가 지원하는 명령어(`/msg`, `/tpa` 등)도 텍스트로 그대로 보낼 수 있어요.
- 로그인 정보(Microsoft 계정 토큰)는 서버에 영구 저장하지 않고 접속 세션 동안만 사용해요.
- 접속은 에뮬레이션이 아니라 실제 마인크래프트 프로토콜로 이루어져서, 서버 입장에서는
  일반 클라이언트가 접속한 것과 동일하게 보여요.

## 사용 방법

1. [mineportal.kr](https://mineportal.kr)에서 Microsoft 계정으로 로그인해요.
2. 접속하고 싶은 서버 주소를 등록해요.
3. 브라우저에서 바로 접속해 채팅을 보내거나(**체험 모드**), IP 제한이 있는 서버라면
   데스크톱 클라이언트를 설치해 접속해요(**정식 모드**).

체험 모드는 설치 없이 바로 쓸 수 있지만, 여러 사람이 같은 경로로 접속하다 보니 서버 입장에선
"같은 곳에서 여러 접속이 온다"고 보일 수 있어 IP 제한/화이트리스트 서버에서는 밴 위험이
있어요. 정식 모드는 데스크톱 클라이언트가 내 PC에서 직접 접속하기 때문에 그런 위험이 없고
IP 제한 서버에서도 안정적으로 동작해요.

## 어떻게 동작하나요

브라우저는 게임 서버에 직접 접속할 수 없기 때문에, 체험 모드에서는 마인포탈 서버가 중간에서
**프록시처럼** 대신 접속해서 채팅을 그대로 전달해줘요. 설치 없이 바로 쓸 수 있는 대신,
여러 사람이 같은 경로를 거치다 보니 IP 제한이 있는 서버에서는 밴 위험이 있어요.

정식 모드는 데스크톱 클라이언트가 그 역할을 사용자 PC로 가져와서, 마인포탈 웹의 지시를 받아
**내 PC가 직접** 게임 서버에 접속해요. 그래서 서버 입장에선 각자의 실제 IP로 들어온
평범한 접속으로 보이고, IP 제한 서버에서도 안정적으로 동작해요.

두 모드 모두 실제 마인크래프트 로그인·채팅 프로토콜을 그대로 사용해서, 서버 쪽에서는
정식 클라이언트가 접속한 것과 다르지 않게 보여요.

## 오픈소스

전체 코드가 공개되어 있어서 누구나 어떻게 동작하는지 확인할 수 있어요.
